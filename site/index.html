Features

Built for the hardware you actually have

Aggressive LOW mode

Fast sRGB approximation (x*x / sqrt), no tonemapping, no vignette, no dithering, linear fog. Targets vanilla FPS on Intel UHD 620 / ancient Chromebooks.

Capability detection

Auto-detects WebGL2, uniform limits, derivative support, draw buffers, frag depth. Gracefully degrades or disables features per-device.

Safe fallbacks

Shader compilation failure? Missing uniform? Unsupported extension? Falls back to vanilla instantly—renderer never crashes.

One-step integration

EaglercraftShaderIntegration.install(renderer) — registers presets, compiles shaders, selects defaults, handles reloads, exposes clean API.

Shared GLSL utilities

Color grading (lift/gamma/gain), fog (exp/exp²/linear), tonemapping (Reinhard/Filmic), vignette, blue-noise dithering, sky color—reused across all 15 programs.

Time-aware

DayTime uniform drives dynamic sky colors, temperature shifts, fog density. Sunrise/sunset actually look different without a skybox.

Installation

Two steps. That's it.

Add the dependency

gradle.kts
repositories {
    mavenCentral()
    maven { url = uri("https://eaglercraft-teavm-fork.github.io/maven/") }
}

dependencies {
    implementation("com.eaglercraft.shaders:eagler-shaders:1.0.0")
}

Initialize once

java
import com.eaglercraft.shaders.EaglercraftShaderIntegration;
import net.minecraft.client.renderer.GameRenderer;

// Call once during client startup
EaglercraftShaderIntegration.install(gameRenderer);

// Later: switch presets, change quality, toggle
ShaderCollection.enable("nightfall");
ShaderCollection.setQuality(ShaderQuality.MEDIUM);
ShaderCollection.toggleShaders();

Hook into the render pipeline (optional)

java
// In GameRenderer.updateCameraAndRender, replace vanilla shader block:
if (GLX.usePostProcess) {
    mc.worldRenderer.renderEntityOutlineFramebuffer();
    // Replace vanilla shader rendering with:
    EaglercraftShaderIntegration.renderShaders(partialTicks, this.useShader);
    mc.getFramebuffer().bindFramebuffer(true);
}

The mod also auto-initializes via FMLClientSetupEvent if you just drop the JAR in mods/. Requires Eaglercraft 26.2+ (1.16.5), Forge 36+, Java 11+.
