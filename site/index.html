Features

Built different

Aggressive LOW mode

Fast sRGB approximation, no tonemapping, no vignette, no dithering, linear fog. Targets vanilla FPS on Intel UHD / ancient Chromebooks.

Capability detection

Auto-detects WebGL2, uniform limits, derivative support, draw buffers. Gracefully degrades or disables features.

Safe fallbacks

Shader compilation failure? Missing uniform? Unsupported extension? Falls back to vanilla instantly—no renderer crash.

One-step integration

EaglercraftShaderIntegration.install(renderer) — registers presets, compiles shaders, selects defaults, handles reloads.

Shared GLSL utilities

Color grading (lift/gamma/gain), fog, tonemapping (Reinhard/Filmic), vignette, dithering, sky color—reused across all presets.

Time-aware

DayTime uniform drives dynamic sky colors, temperature shifts, fog density—sunrise/sunset actually look different.

Installation

Two steps. That's it.

gradle.kts
repositories {
    mavenCentral()
    maven { url = uri("https://eaglercraft-teavm-fork.github.io/maven/") }
}

dependencies {
    implementation("com.eaglercraft.shaders:eagler-shaders:1.0.0")
}
java
import com.eaglercraft.shaders.EaglercraftShaderIntegration;
import net.minecraft.client.renderer.GameRenderer;

// Call once during client startup, after GameRenderer exists
EaglercraftShaderIntegration.install(gameRenderer);

// Later: switch presets, change quality, toggle
ShaderCollection.enable("nightfall");
ShaderCollection.setQuality(ShaderQuality.MEDIUM);
ShaderCollection.toggleShaders();
java
// In GameRenderer.updateCameraAndRender, replace vanilla shader rendering:
if (GLX.usePostProcess) {
    mc.worldRenderer.renderEntityOutlineFramebuffer();
    // Replace vanilla shader block with:
    EaglercraftShaderIntegration.renderShaders(partialTicks, this.useShader);
    mc.getFramebuffer().bindFramebuffer(true);
}

The mod also auto-initializes via FMLClientSetupEvent if you just drop the JAR in mods/.
